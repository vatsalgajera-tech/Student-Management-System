<h1 align="center">🎓 Student Management System</h1>

<p align="center">
  A web-based Student Management System for managing courses, subjects, student registrations, and admin authentication.
</p>

---

## 📌 Overview

The Student Management System is a PHP and MySQL application designed to simplify student record management.

It provides modules for:
- Course Management
- Subject Management
- Student Registration
- Admin Login
- Search and Reporting

---

## ✨ Features

### 👨‍🎓 Student Module
- Student registration form
- Personal and academic information storage
- Course selection

### 📚 Course Module
- Add and manage courses
- Store course codes and full names

### 📝 Subject Module
- Assign subjects to courses
- Manage subject details

### 🔐 Admin Module
- Secure admin login
- Dashboard for managing records
